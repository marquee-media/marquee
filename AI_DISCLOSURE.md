# AI Disclosure

## How this project was built

Marquee was designed and directed by its maintainer, with AI-assisted code generation (primarily ChatGPT). The human was responsible for:

- All feature design and architecture decisions
- Prompting, reviewing, and testing generated code
- Identifying and reporting bugs
- Final approval of what ships

## What this means for you

- The code is 100% open. Read it, audit it, fork it.
- If you find something that looks wrong, open an issue.
- If you want to fix something, open a PR. You don't need to understand the whole codebase.
- The maintainer is still learning Rust. Not everything here is idiomatic or optimal. That's okay.

## What it doesn't mean

- This is not a "prompt dump." The design, scope, and direction are human decisions.
- The AI didn't choose what to build. The user did.
